7. Example problems

The SPARTA-MSMC distribution includes one self-contained example in examples/msmc_circle. It models hypersonic argon flow over a two-dimensional half-cylinder using a 50 x 25 base grid with local refinement. The directory contains the input script, gas data, surface geometry, MPI launcher, and MATLAB post-processing scripts.

See examples/README.md and examples/msmc_circle/README.md for the complete build, run, output, and post-processing workflow.
